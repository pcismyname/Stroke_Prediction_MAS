# Data card

The primary dataset (`data/raw/healthcare-dataset-stroke-data.csv`, 317 KB) **is committed** so that a fresh clone runs end to end. It is used only for this course, credited to its author below, and must not be reused for other purposes. All other data files (S3E2, interim and processed outputs) are not committed.

## How to download

Manually: log in to Kaggle, download from the links above, and unzip into the folders listed.

With the Kaggle CLI (`pip install kaggle`, API token in `~/.kaggle/kaggle.json`):

```bash
kaggle datasets download -d fedesoriano/stroke-prediction-dataset -p data/raw --unzip
```

## Known limitations
- The original data source and population are undisclosed, so estimates can't be generalised to a specific clinic or country.
- Cross-sectional: we don't know if BMI, glucose etc. were measured before or after the stroke (relevant to the missing-BMI pattern, see [knowledge_base/04](../knowledge_base/04_missing_data_mechanisms.md)).
- Glucose units are not stated (values match mg/dL).
- Only 249 events, which limits model complexity and subgroup analyses.
